# 🛒 Alışveriş Listesi Uygulaması (Shopping List App)

Bu proje, Vanilla JavaScript kullanılarak geliştirilmiş, kullanıcı dostu ve dinamik bir alışveriş listesi uygulamasıdır. Günlük alışveriş ihtiyaçlarınızı hızlıca listeleyip yönetmenize olanak tanır.

## 🚀 Özellikler
- **Dinamik Ürün Ekleme:** Input alanına yazdığınız ürünleri "Enter" tuşu veya "Ekle" butonu ile listeye dahil edebilirsiniz.
- **Tekli ve Toplu Silme:** İster ürün bazlı silme yapabilir, isterseniz "Tümünü Kaldır" butonu ile listeyi tek seferde temizleyebilirsiniz.
- **Giriş Temizleme:** Yazım esnasında görünen çarpı (X) butonu ile giriş alanını hızlıca temizleyebilirsiniz.
- **Boş Liste Kontrolü:** Liste boşaldığında kullanıcıya otomatik bir bilgilendirme mesajı gösterilir.
- **Responsive Tasarım:** CSS Media Queries kullanılarak mobil, tablet ve masaüstü cihazlara tam uyumlu hale getirilmiştir.

## 🛠️ Kullanılan Teknolojiler
- **HTML5:** Sayfa yapısı ve hiyerarşisi.
- **CSS3:** Modern UI, cam (glassmorphism) efekti ve animasyonlar.
- **JavaScript (ES6+):** DOM manipülasyonu ve uygulama mantığı.
- **Bootstrap Icons:** Kullanıcı arayüzü simgeleri.
